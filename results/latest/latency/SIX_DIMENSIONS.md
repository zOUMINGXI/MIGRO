# 六项时延统计（现有日志整理，无实验重跑）

六项是分层指标，存在包含关系，不能相加。单位分别标注；— 表示未记录，不表示零。只表示本次实际执行条件下的记录，不能当作统一硬件/并行/缓存条件下的速度排名。

## 统计口径

1. **写入/构建**：保留的 build/WRITE 计时；若来自恢复起止点或进行中进度，会明确标注。不是一律完整冷启动写入。
2. **检索、准备与等待残差**：单题整体响应减去内部 reader 计时。含排队、资源争用及批次分摊差异，只是估算，不能称为纯检索时延。
3. **回答生成**：cost.seconds，LSTMem BEAM 使用原生 answer_seconds。部分记录为批次分摊耗时。
4. **单题整体响应**：仅采用明确包围 retrieval→answer 的计时；缺失时不拿生成时间顶替。
5. **历史任务观测历时**：保留的任务分配/续跑起点至结束时间，可能包含等待、暂停并漏掉恢复前工作。
6. **修复/重试开销**：有计时的 extra_call 日志事件秒数与事件数、调度重试次数分别统计；不是完整失败成本。

每个指标的均值、中位数、P95、样本覆盖率、来源和缺失标记在 six_dimensions_long.csv；总览在 six_dimensions_summary.csv。
