# Third-party references

The repository includes the MIGRO memory runtime, benchmark entry points and reporting tools. Obtain baseline implementations, backbone and reranker models, and benchmark datasets from their original sources. Shared runtime checkpoints are prepared separately with component provenance and license notices.

Methods:
- PlugMem: https://github.com/TIMAN-group/PlugMem
- mem0: https://github.com/mem0ai/mem0
- TiMEM: https://github.com/TiMEM-AI/TiMEM
- A-Mem: https://github.com/WujiangXu/A-mem
- LSTMem: https://github.com/Longchentong/LSTMem
- TransMem: https://github.com/Haodong-Lei-Ray/TransMem
- Doc-to-LoRA: https://github.com/SakanaAI/doc-to-lora

Obtain datasets, backbones and released adapters from their respective official sources and follow their licenses. A citation or reference is not a redistribution grant. Full setup instructions and citation metadata will accompany the later implementation release.
